# Little Life · repository review

**37 acceptance criteria · 23 PASS / 7 FAIL / 7 WARN.** Counts cover Section 1. The three highest-priority problems are:

1. A temporary storage read failure can permanently overwrite an entire ledger or task list with an empty array, even if the user makes no edits.
2. Both AI endpoints can spend the server owner’s OpenAI budget without an application-level caller check, quota or concurrency limit.
3. The checked-in native release configuration lacks a server origin for both parsing and transcription.

TypeScript passed with `tsc --noEmit --incremental false`. ESLint and its configuration are absent, and Expo lint would bootstrap them. Git confirmed that `.env` is ignored and untracked, with no commits for that path in locally reachable history. This was a source review across native and the configured web target. Device timing, force-quitting Expo Go and live model output were not exercised.

## 2. Other findings

1. [FAIL] **A failed read triggers a destructive write.** `src/lib/store.tsx:68-78,97-118`. A transient read error yields an empty array, then setting `loaded` immediately writes it over the original key. Track read status and dirty state per key, preserve the original bytes on failure, and offer a retry before allowing edits to replace unread data.
2. [FAIL] **Any reachable caller can consume upstream AI capacity.** `src/app/api/parse+api.ts:179-205,211-228`, `src/app/api/transcribe+api.ts:20-31,42-67`. Both routes forward accepted requests using server credentials, with no caller authorization, quota or concurrency control in the repository. Enforce caller access and request, cost and concurrency budgets server-side or at the deployment gateway.
3. [FAIL] **A native release has no checked-in API destination.** `app.json:22-28`, `src/lib/api.ts:42-50,167-173,201-215`. The relative parse URL and the transcription uploader depend on an origin, leaving release users dependent on external build configuration for both AI features. Set the deployed HTTPS origin on the Expo Router plugin and verify both routes from a release build. [Expo native deployment](https://docs.expo.dev/router/web/api-routes/#native-deployment)
4. [FAIL] **Home accepts edits before storage finishes loading.** `src/app/(tabs)/index.tsx:50-55,76-86,99-109`, `src/lib/store.tsx:97-105,120-140`. A save during a slow read can show success and clear the input before hydration replaces the new record with an older snapshot. Keep the draft editable and gate the save until its list is ready, or replay queued mutations over the loaded state.
5. [FAIL] **Save success precedes durability.** `src/lib/store.tsx:81-86,111-118`, `src/app/(tabs)/index.tsx:99-109`, `src/app/(tabs)/todo.tsx:114-125`. Write failures are swallowed and force-quitting before the effect finishes can lose an acknowledged change. Expose mutation completion and errors to callers, retain failed edits for retry, and acknowledge a save after its write succeeds.
6. [WARN] **Concurrent writers can lose independent edits.** `src/lib/store.tsx:68-74,81-86,94-118,120-140`. Each provider reads once and replaces the entire stored list, so two web tabs editing the same starting snapshot can overwrite each other even if storage executes writes in order. Serialize pending writes per key within a provider and use per-record transactional updates or revision checks across writers.
7. [FAIL] **Body limits apply after allocation.** `src/app/api/parse+api.ts:186-197`, `src/app/api/transcribe+api.ts:27-51`, `src/lib/limits.ts:3-7`. The 300-character check follows full JSON parsing, and the 10 MiB file check follows multipart parsing when the total size is undeclared. Enforce an actual byte ceiling at ingress or while reading the stream, bound multipart fields, and reject unsupported media before forwarding.
8. [FAIL] **Web voice uploads lose the audio.** `src/lib/api.ts:200-215`, `src/app/api/transcribe+api.ts:42-46`, `node_modules/expo-audio/src/AudioRecorder.web.ts:170-182`. The browser recorder returns a blob URL, but appending the native file descriptor to browser FormData produces a text part. Resolve the blob URL to a Blob on web and append it with its actual media type and an appropriate filename.
9. [FAIL] **Both web task deletion controls are inert.** `src/app/(tabs)/todo.tsx:128-145`, `src/components/todo/task-row.tsx:298-311`, `node_modules/react-native-web/dist/exports/Alert/index.js:10-12`. Both paths rely on an alert callback that never fires on web. Share a confirmation helper with the platform-specific behavior already used in `src/components/ledger/expense-row.tsx:26-35`.
10. [WARN] **Recording startup and teardown can overlap.** `src/components/home/use-voice-input.ts:47-65,78-105`, `src/app/(tabs)/index.tsx:76-84`. Mic and Send remain available during permission and preparation, and a failed stop can still upload a URI from an unfinished recording. Lock transitions synchronously, stop on recorder errors, and restore audio mode on failed preparation.
11. [WARN] **Keyboard and touch share an asynchronous submission guard.** `src/app/(tabs)/index.tsx:76-96,146-148,169-175`. Two submit callbacks before the next render can launch two billable parses and apply responses to the same draft. Acquire an in-flight ref before starting the request and release it when the confirmation state is ready.
12. [WARN] **Task completion depends on a row staying mounted.** `src/components/todo/task-row.tsx:124-133,169,226-243,275-277`, `src/app/(tabs)/todo.tsx:190-197`. Scrolling a pending row out of the list’s render window can cancel its commit after the haptic has already fired. Keep the pending mutation in the screen or store and let the row own only its animation.
13. [WARN] **Calendar summaries can go stale overnight.** `src/app/(tabs)/ledger.tsx:11-31,41-52`, `src/components/todo/task-row.tsx:358-360,419-435`. No state change occurs at local midnight, so Today, overdue status and the current-month header can stay stale while displayed. Refresh a shared local-day value at midnight and on foregrounding, and pass it into list rendering.
14. [FAIL] **A decimal comma can inflate an expense.** `src/components/home/confirm-sheet.tsx:174-185`, `src/components/home/draft.ts:63-82,106-113`. A user entering `12,50` on a localized decimal keyboard sees that text in the form but saves $1,250.00. Parse the locale’s decimal separator or explicitly reject ambiguous grouping, then show the normalized currency value before commit.
15. [WARN] **Important text is small or hard to distinguish.** `src/theme.ts:9-19,41-46`, `src/components/home/confirm-sheet.tsx:97-98,269-275,338,416`, `src/components/todo/task-row.tsx:524-535`. Explanatory notices render at 14 pt, and white Save text on coral or teal and amber overdue dates on white have low contrast. Raise prose to at least 15 pt and choose foreground/background pairs with at least 4.5-to-1 contrast for ordinary text.
16. [WARN] **Screen readers miss task deadlines.** `src/components/todo/task-row.tsx:365-375,390-397,419-435`. The row groups the visual date under an explicit “Edit [title]” label, and neither accessible control includes the date or overdue state. Include both in the row’s accessible description.
17. [WARN] **The parse timeout ends at the response headers.** `src/lib/api.ts:62-90`, `src/app/(tabs)/index.tsx:84-96`. A stalled response body can leave Home waiting past its 15-second deadline and delay the manual-entry form. Keep the abort timer active through body consumption and surface a body timeout as a recoverable parse error.
18. [WARN] **Voice-to-text silently discards excess words.** `src/app/(tabs)/index.tsx:63-68,159-165`, `src/lib/limits.ts:3-4`. Appending a transcript to a nearly full input can discard its amount or due date while showing only a character counter. Tell the user when a transcript was shortened and let them recover or edit the omitted text.
